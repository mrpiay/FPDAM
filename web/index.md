## Módulos { #modulos }

<div class="fp-curso fp-curso-1" markdown>

### 1.º DAM · 395 h

<div class="grid cards" markdown>

-   :material-server-network:{ .lg .middle } **MP0483 · Sistemas informáticos**

    <span class="fp-course">155 h · 9 unidades</span>

    Hardware, sistemas operativos libres y propietarios, virtualización, redes IPv4/IPv6 y dominios. El proyecto consiste en montar la infraestructura de una pequeña empresa de software.

    [:octicons-arrow-right-24: Acceder al módulo](1DAM/0483-sistemas-informaticos/README.md)

-   :material-language-java:{ .lg .middle } **MP0485 · Programación**

    <span class="fp-course">240 h · 11 unidades</span>

    Java 25 desde cero hasta POO, colecciones y *streams*, ficheros, JavaFX, JDBC y bases de datos orientadas a objetos. El proyecto es una aplicación de gestión que se entrega en tres versiones.

    [:octicons-arrow-right-24: Acceder al módulo](1DAM/0485-programacion/README.md)

</div>

</div>

<div class="fp-curso fp-curso-2" markdown>

### 2.º DAM · 382 h

<div class="grid cards" markdown>

-   :material-monitor-dashboard:{ .lg .middle } **MP0488 · Desarrollo de interfaces**

    <span class="fp-course">191 h · 9 unidades</span>

    JavaFX, usabilidad y accesibilidad, componentes, informes, interfaces naturales (voz, gestos, realidad aumentada), distribución y pruebas.

    [:octicons-arrow-right-24: Acceder al módulo](2DAM/0488-desarrollo-de-interfaces/README.md)

-   :material-cellphone:{ .lg .middle } **MP0489 · Programación multimedia y dispositivos móviles**

    <span class="fp-course">191 h · 10 unidades</span>

    Android con Kotlin y Jetpack Compose, persistencia, servicios web, sensores y mapas, multimedia, y videojuegos 2D con Godot y 3D con Unity.

    [:octicons-arrow-right-24: Acceder al módulo](2DAM/0489-programacion-multimedia-y-dispositivos-moviles/README.md)

</div>

</div>

Cada módulo incluye su ficha, el currículo oficial literal, la programación didáctica (secuencia, horas, matriz de cobertura y evaluación), los registros de decisión y las unidades con contenidos, actividades, práctica evaluable y rúbrica.

<div class="grid cards fp-features" markdown>

-   :material-scale-balance: **Normativa citada**

    Cada RA, criterio y dato de horas lleva su fuente: norma, anexo, elemento y enlace al BOE o al DOG.

-   :material-check-all: **Cobertura completa**

    Todos los criterios de evaluación de cada módulo se trabajan y se evalúan en al menos una unidad.

-   :material-compare-horizontal: **Decisiones justificadas**

    Cada tecnología se compara con alternativas usando ocho [criterios](plantillas/criterios-de-decision.md), y siempre hay un plan B.

-   :material-briefcase-outline: **Proyectos reales**

    Encargos de clientes ficticios con historias de usuario, Git con *pull requests*, pruebas e integración continua desde 1.º.

</div>
